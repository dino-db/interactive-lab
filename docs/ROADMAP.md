# Roadmap

This is a direction for PDB Labs Interactive Lab, **not a promise of release dates**.

## V4 BETA — included

- Python editor, output console and local autosave.
- Algorithm Lab with 16 searchable, filterable visualizations.
- Python execution trace viewer with line highlighting, local variables and call stack.
- Responsive layout and dark/light theme.

## Before a public hosted release

- [ ] Validate Monaco and Pyodide in a real deployed browser environment.
- [ ] Test real Python execution and the debugger worker across browsers.
- [ ] Review accessibility, keyboard navigation and mobile behavior.
- [ ] Add customizable inputs to the mathematics and dynamic programming examples.
- [ ] Review dependency loading, security, CSP and error handling.
- [ ] Establish versioning, licensing and contribution policy.

## Ideas for future labs

- More algorithms: graph paths, trees, recursion, optimization, geometry.
- Data & Simulation Lab.
- AI Lab and explainable model demos.
- Interactive educational experiments.
